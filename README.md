# MonIPTV (Android)

Projet Android complet prêt pour un nouveau dépôt GitHub avec build automatique via **GitHub Actions**.

## Ce qui est inclus
- **Lecteur (`PlayerScreen`)** : bouton coupure son (`🔇 Son coupé` / `🔊 Son actif`), modes d'affichage en direct (`Plein écran`, `16:9`, `4:3`, `3:4`), repli automatique Live TV (`.m3u8` -> `.ts`) sans quitter l'application, et bouton **Réessayer**.
- **Écran Paramètres (`SettingsScreen`)** : format d'affichage par défaut, démarrage muet optionnel, effacement de l'historique et déconnexion.
- **Logo** : place ton image renommée `ic_launcher_source.png` dans `app/src/main/res/mipmap-nodpi/` (remplaçant l'icône par défaut incluse) avant ou après le push.
